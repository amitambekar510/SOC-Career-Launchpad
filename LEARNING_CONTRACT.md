# The Learning Contract

This project is built so that **you** become capable, not so that a tool can tell you answers.
By using it as a learner you agree, with yourself, to:

1. **Think before you check.** Try every question yourself first. Hints are fine. Answer-copying isn't.
2. **Finish a section before its checkpoint.** Read it, try the examples, then answer.
3. **Accept the gate.** If you don't pass, you review and retry. It costs nothing but pays off later.
4. **Be honest with your record.** Don't edit your progress file or ask an AI to "mark it as done". Your scorecard is for *you*.
5. **Write your own notes.** Putting it in your own words is what makes it stick.
6. **Practice safely and legally.** Only on systems you own or have written permission to test.
7. **Protect confidentiality.** Never paste real employer or client data into any tool.
8. **Ask for help.** Stuck? Ask the AI tutor, a mentor, or open an Issue. Asking is part of learning.

> *"The best analyst in the room is the one who stayed curious when it was inconvenient."*

AI tutors connected to this project follow the same contract, see [ai/TUTOR_POLICY.md](ai/TUTOR_POLICY.md).
