# Glossary

| Term | Plain meaning |
|---|---|
| **AAA** | Authentication, Authorization, Accounting |
| **APT** | Advanced Persistent Threat: a skilled, long-running attacker |
| **ATT&CK** | MITRE's catalogue of attacker tactics and techniques |
| **Beaconing** | Malware checking in with its controller at regular intervals |
| **Brute force** | Guessing passwords over and over |
| **C2 / C&C** | Command and Control: how attackers remotely control infected machines |
| **CIA triad** | Confidentiality, Integrity, Availability |
| **CIDR** | Notation like /24 that says how big a network is |
| **Correlation** | Connecting events from different sources to see the bigger story |
| **DHCP** | Gives devices their IP addresses automatically |
| **DLP** | Data Loss Prevention: tools that stop sensitive data leaving |
| **DMZ** | A buffer network for internet-facing servers |
| **DNS** | Turns domain names into IP addresses |
| **EDR** | Endpoint Detection and Response |
| **Exfiltration** | Data being stolen out of the organization |
| **False positive** | An alert about something harmless |
| **Hash** | A fingerprint of a file |
| **IDS / IPS** | Intrusion Detection / Prevention System |
| **IOA** | Indicator of Attack (behavior) |
| **IOC** | Indicator of Compromise (clue left behind) |
| **IR** | Incident Response |
| **Kill Chain** | The 7-stage model of an attack |
| **KQL** | Kibana Query Language |
| **L1 / L2 / L3** | Analyst tiers: triage, investigation, expert |
| **Lateral movement** | Attacker hopping from machine to machine |
| **LOLBin** | "Living off the land" binary: a legitimate built-in tool abused by attackers |
| **MFA** | Multi-Factor Authentication |
| **Mutex** | A name malware creates to mark a machine as already infected |
| **Persistence** | Ways attackers survive reboots and stay in |
| **Phishing** | Fake messages designed to steal info or deliver malware |
| **Playbook / runbook** | Step-by-step instructions for handling a situation |
| **Ransomware** | Malware that encrypts files and demands payment |
| **SIEM** | Security Information and Event Management |
| **SLA** | Service Level Agreement: promised response times |
| **SOAR** | Security Orchestration, Automation and Response |
| **SOC** | Security Operations Center |
| **Sysmon** | Free Microsoft tool for detailed Windows endpoint logging |
| **Threat intelligence** | Information about attackers, their tools and indicators |
| **Threat hunting** | Proactively searching for hidden attackers |
| **TTPs** | Tactics, Techniques and Procedures: how attackers operate |
| **True positive** | An alert about a real threat |
| **UEBA** | User and Entity Behavior Analytics |
| **VLAN** | A logical network split on shared hardware |
| **WAF** | Web Application Firewall |
| **Zero-day** | A flaw with no patch yet |
